# Hanuman Ji: The Sanjeevani Quest

A self-contained HTML5 Canvas arcade flight game inspired by the Sanjeevani journey.

## Features
- Keyboard, pointer, and touch flight controls
- Procedural sky, ocean, and Himalayan parallax scenery
- Collectible Sanjeevani herbs, golden lotuses, and divine power-ups
- Prana/health, score, persistent high score, sound effects, particles, and screen shake
- Four story chapters with milestone rewards and healing
- Pause/resume, responsive layout, accessibility labels, and reduced-motion consideration
- Installable/offline-capable PWA shell (after the first successful load on a supported browser)

## Play
Once GitHub Pages is enabled for this repository, the game folder URL is:
https://mnijhara.github.io/Mitesh/sanjeevani-quest/

## Publish
The repository is `mnijhara/Mitesh`, and the game lives under `sanjeevani-quest/` to avoid replacing the existing repository homepage. To serve it from GitHub Pages, open Settings → Pages and select **Deploy from a branch**, branch **main**, folder **/(root)**. GitHub will then serve the subfolder at the URL above. This folder layout does not require a backend.

## Controls
- **Ascend:** Space, Up Arrow, or W
- **Dive:** Down Arrow or S
- **Pause/resume:** P, Escape, or the pause button
- **Touch:** Drag vertically on the playfield or hold the on-screen Ascend/Dive controls
- **Chant:** Tap “Jai Shri Ram” for a celebratory particle burst
