# Hanuman Ji: The Sanjeevani Quest

A browser-based mythological arcade flight game built with HTML5 Canvas.

## Play
Open the game page: https://mnijhara.github.io/Mitesh/sanjeevani-quest/

## Controls
- **Ascend:** Space, Up Arrow, or W
- **Dive:** Down Arrow or S
- **Pause / resume:** P or the pause button
- **Touch:** Drag vertically across the playfield or use the on-screen controls
- Collect Sanjeevani herbs to earn points and restore Prana; collect golden lotuses and power-ups; avoid storm clouds, sea demons, and shadow orbs.

## GitHub Pages
This game is in the `sanjeevani-quest/` folder of the `Mitesh` repository. In GitHub, open **Settings → Pages** and ensure deployment is set to **Deploy from a branch**, branch **main**, folder **/(root)**. If Pages is already enabled for this repository, the game should appear at the URL above after deployment finishes.

## Project status
This is an enhanced prototype, not a claim of AAA production quality. A bigger release would benefit from original art and music, mobile playtesting, accessibility review, gameplay balancing, automated tests, and deeper progression.
